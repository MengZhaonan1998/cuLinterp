# cuLinterp
CUDA implementation of 1D/2D linear interpolation. 
## Features
* Header-only library: All functions are coded in a single header file. 
* C-style implementation: No C++ features are used.
* GPU-accelerated: Leverages CUDA for high-performance interpolation.
* Example codes provided: Example usage is included in test.cu to help users get started quickly.
* Matlab verification: Generates results aligned with Matlab's interp
